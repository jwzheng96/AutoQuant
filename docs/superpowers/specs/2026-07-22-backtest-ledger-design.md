# AutoQuant A 股回测账本设计

- 日期：2026-07-22
- 状态：账本核心已实施；数据状态持久化与控制台集成待完成
- 边界：研究与模拟成交，不启用真实下单

## 1. 目标

建立可复现、可审计、默认失败关闭的 A 股日频回测执行核心。它负责资金、持仓、
订单校验、成交假设、费用和逐日净值，不负责生成“保证盈利”的策略结论。

## 2. 官方规则依据与版本

- 上海证券交易所《交易规则（2026 年修订）》自 2026-07-06 生效：普通竞价买入
  100 股或其整数倍，科创板限价申报最低 200 股，股票交收前不得卖出，主板股票
  涨跌幅限制为 10%。
- 深圳证券交易所《交易规则（2026 年修订）》规定普通竞价买入 100 股或其整数倍。
- 中国结算现行上海市场收费表列示 A 股交易过户费按成交金额 0.01‰ 向买卖双方收取。
- 财政部、税务总局 2023 年第 39 号公告自 2023-08-28 起将证券交易印花税减半。

- https://www.sse.com.cn/lawandrules/sselawsrules2025/trade/universal/c/c_20260424_10816492.shtml
- https://docs.static.szse.cn/www/lawrules/rule/trade/current/W020260424690713155663.pdf
- https://www.chinaclear.cn/zdjs/fbzyls/202506/9d22b74d9f2e40edb67b44d1f6596f18/

交易所规则、税费和券商佣金会变化。每个回测结果必须保存规则版本、费用版本、
生效日期和所有成交假设。历史风险警示状态、上市前五个交易日状态缺失时，不得
猜测涨跌停比例。

## 3. 账本不变量

- 只支持现金账户多头股票；不允许负现金、裸卖空或同一证券 T+0；
- 每个交易日开始时才解锁此前买入的可卖数量；
- 买入数量遵守最低申报量与步长；零股只能一次性卖出；
- 停牌、零成交量、封死涨停买入和封死跌停卖出均拒单；
- 成交额、佣金、印花税、过户费和现金变化使用 `Decimal`，费用按分取整；
- 每个成交或拒单形成哈希链事件，任何顺序或内容变化都会改变末端哈希；
- 日线成交只使用当日开盘前已提交的订单，成交价基于开盘价和显式滑点；
- 单笔参与率上限限制成交容量，超过容量默认拒绝，不假装无限流动性；
- 研究结果记录数据清单哈希和 `as_of`，禁止从未验证的裸数据直接宣称绩效。

## 4. 第一阶段成交模型

- 订单类型：日频、开盘成交、立即成交或拒绝；
- 成交价格：开盘价叠加方向性滑点，并限制在当日高低价范围内；
- 流动性：订单数量不得超过当日成交量乘以参与率上限；
- 费用：券商佣金可配置且设最低佣金；卖出收取印花税；买卖双方收取过户费；
- 涨跌停：优先使用 Tushare `stk_limit` 在该交易日给出的精确上下限；规则簿中的
  比例只用于独立校验和缺口诊断，`stk_limit` 未进入时点清单时不开放回测运行。

日线 OHLC 无法重建盘口排队和盘中逐笔成交，因此该模型只能用于保守研究。进入
模拟盘前必须使用分钟或逐笔数据做成交敏感性分析。

## 5. 完成证据

- T+1、申报数量、现金、持仓和零股约束均有边界测试；
- 涨跌停、停牌、流动性和费用模型均有确定性测试；
- 相同输入产生相同账本哈希和绩效；
- 策略不能读取当日成交之后的信息来决定当日开盘订单；
- 数据清单、规则与费用版本进入结果；
- 单元测试、Ruff 和严格 mypy 通过。

## 6. 仍不满足实盘的条件

完成本账本后仍需组合构建、公司行动现金流、样本外/滚动验证、风险预算、模拟盘、
QMT 订单状态机、券商对账、监控告警、程序化交易报告义务评估和人工紧急停机。
